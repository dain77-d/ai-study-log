# Masked Autoencoders Are Scalable Vision Learners (MAE)

- 링크: https://arxiv.org/abs/2111.06377
- 저자: Kaiming He, Xinlei Chen, Saining Xie, Yanghao Li, Piotr Dollár, Ross Girshick (Facebook AI Research)
- 발표: arXiv 2021-11 (v3 2021-12-19), CVPR 2022 (Oral)

> 왜 이 논문인가: CVPR 2022 구두 발표(oral)로 채택된 FAIR의 대표적 자기지도 비전 논문이며, 이후 VideoMAE, 각종 ViT 사전학습 레시피의 기반이 된 방법이다. (이번 실행 환경에서 Semantic Scholar API가 차단되어 인용 수는 직접 확인하지 못했다. 위 venue 정보는 논문 본문이 아니라 내가 알고 있는 사실이며, 본문 분석은 arXiv v3 PDF 전문을 기준으로 했다.)

## 한 줄 요약
이미지 패치의 75%를 무작위로 가려 놓고, **보이는 25%만 인코더에 넣고** 가벼운 디코더가 마스크 토큰과 함께 픽셀을 복원하게 하면, 사전학습이 3배 이상 빨라지면서 ViT-H가 ImageNet-1K 데이터만으로 87.8%를 달성한다.

## 배경: 수업에서 배운 것과의 연결
- **자기지도 학습/ViT**: 수업에서 다룬 contrastive(MoCo, SimCLR)와 BYOL류는 두 view 간 유사도에 의존하므로 강한 augmentation이 필수다. MAE는 BERT식 "일부를 지우고 복원"을 비전에 가져온 것이다.
- **VAE/오토인코더**: 입력을 잠재 표현으로 압축했다 복원하는 구조는 같지만, 여기서는 입력을 *가리는* denoising autoencoder의 일종이고 인코더/디코더가 비대칭이다.
- **Transformer**: ViT는 패치를 시퀀스로 다루므로 "토큰을 제거"하는 것이 자연스럽다. 합성곱은 규칙 격자 위에서 동작해서 mask token을 넣기 어렵다는 점(논문 Intro (i))이 그동안 비전에서 BERT식 방법이 늦은 이유 중 하나였다.
- **LLM 사전학습**: GPT/BERT가 NLP를 바꾼 것처럼 "단순한 목표 + 스케일"을 비전에서 재현하려는 시도다.

## 문제 설정
논문은 NLP와 비전에서 masked autoencoding이 왜 다르게 작동하는지 세 가지로 분석한다 (Sec.1).
1. 아키텍처: CNN은 mask token/위치 임베딩 통합이 어렵다 → ViT가 해결.
2. **정보 밀도**: 언어는 의미 밀도가 높아 15%만 가려도 어렵지만, 이미지는 공간적 중복이 커서 인접 패치로 쉽게 보간된다. → 아주 높은 비율로 가려야 의미 이해가 필요한 과제가 된다.
3. **디코더 역할**: 언어는 단어(의미 수준 높음)를 예측하지만 비전은 픽셀(의미 수준 낮음)을 예측하므로, 디코더 설계가 잠재 표현의 의미 수준을 좌우한다.

## 방법
**전체 구조 (Fig. 1)**: 사전학습 후 디코더는 버리고, 인코더만 가리지 않은 전체 패치에 적용해 인식에 쓴다.

1. **Masking**: ViT처럼 이미지를 겹치지 않는 패치로 나누고, 균일 분포로 **비복원 무작위 샘플링**해 일부만 남긴다(기본 마스킹 비율 75%). 균일 분포는 중앙 편향을 막는다.
2. **인코더**: 표준 ViT를 **보이는 패치에만** 적용한다(선형 투영 + 위치 임베딩 + Transformer 블록). 마스크 토큰은 인코더에 넣지 않는다.
3. **디코더**: 입력은 (인코딩된 보이는 패치) + (공유되는 학습 가능한 mask token). 전체 토큰에 위치 임베딩을 다시 더하고 또 다른 Transformer 블록들을 통과시킨다. 기본값은 깊이 8, 너비 512로 토큰당 FLOPs가 ViT-L의 약 9%다. 인코더와 폭이 다르므로 사이에 선형 투영을 둔다.
4. **목표/손실**: 마스크된 패치의 픽셀 값에 대한 **MSE, 마스크된 패치에서만** 계산한다(전체 픽셀에 계산하면 약 0.5% 하락, 각주 1). 변형으로 패치별 평균/표준편차로 정규화한 픽셀을 타깃으로 하면 표현이 더 좋아진다.
5. **구현 트릭**: 토큰 리스트를 랜덤 셔플 → 뒤쪽을 잘라냄 → 인코딩 → mask token을 붙이고 → 셔플을 되돌려(unshuffle) 위치에 맞춘다. 희소 연산이 필요 없고 오버헤드가 무시할 만하다.

**사전학습 설정 (Table 8)**: AdamW, base lr 1.5e-4 (선형 스케일링 lr = base × batch/256), weight decay 0.05, β=(0.9, 0.95), batch 4096, cosine, warmup 40 epoch, 증강은 RandomResizedCrop만. color jitter/drop path/gradient clip 미사용, Xavier uniform 초기화, sin-cos 위치 임베딩, 보조 dummy token을 class token처럼 사용(평균 풀링도 비슷하게 동작).

**평가 프로토콜**: end-to-end fine-tuning (Table 9: lr 1e-3, layer-wise lr decay 0.75, mixup 0.8, cutmix 1.0, drop path 0.1/0.2, 50~100 epoch), linear probing (Table 10: LARS, 인코더 특징 앞에 affine 없는 BatchNorm).

## 실험 설정
- 사전학습: ImageNet-1K 학습셋 (라벨 없음). 평가: IN1K 224×224 단일 crop top-1.
- 모델: ViT-B/16, L/16, H/14. 어블레이션은 ViT-L/16, 800 epoch.
- 비교: 처음부터 학습한 지도 ViT(저자 구현), DINO, MoCo v3, BEiT.
- 전이: COCO(Mask R-CNN + FPN 적응, 단일 스케일 ViT를 4구간으로 나눠 conv로 up/down-sample), ADE20K(UperNet), iNaturalist 2017/18/19, Places205/365.

## 결과
**ImageNet-1K fine-tuning (Table 3)**: scratch 82.3/82.6/83.1(B/L/H), DINO 82.8(B), MoCo v3 83.2/84.1, BEiT 83.2/85.2, **MAE 83.6 / 85.9 / 86.9**, ViT-H448은 **87.8%**. 이전 IN1K 단독 최고는 87.1%(512 해상도, VOLO)였다. 1600 epoch 학습 기준이지만 MAE는 ViT-L 128 TPU-v3 코어에서 31시간, MoCo v3는 300 epoch에 36시간이었다.

**지도 사전학습 대비 (Fig. 8)**: 모델이 클수록 scratch 대비 이득이 커져, JFT-300M 지도 사전학습과 비슷한 스케일링 추세를 IN1K만으로 보인다.

**전이 (Table 4, 5)**
| 방법 | COCO APbox (B/L) | COCO APmask (B/L) | ADE20K mIoU (B/L) |
|---|---|---|---|
| supervised | 47.9 / 49.3 | 42.9 / 43.9 | 47.4 / 49.9 |
| MoCo v3 | 47.9 / 49.3 | 42.7 / 44.0 | 47.3 / 49.1 |
| BEiT | 49.8 / 53.3 | 44.4 / 47.1 | 47.1 / 53.3 |
| MAE | 50.3 / 53.3 | 44.9 / 47.2 | 48.1 / 53.6 |

**분류 전이 (Table 6)**: iNat 2017 ViT-H448 83.4 (이전 최고 75.4), iNat 2018 86.8 (81.2), iNat 2019 88.3 (84.1), Places205 66.8 (66.0), Places365 60.3 (58.0). 이전 최고 중 Places는 10억~35억 장 사전학습 모델이다.

**Linear probing**: ViT-L 75.8% (Table 12, 부록 B) vs MoCo v3 77.6% — 여전히 contrastive보다 낮다. 그러나 iGPT-XL 72.0, BEiT ViT-L 52.1(저자 재현)보다는 높다.

**강건성 (Table 13)**: ViT-H에서 IN-Adversarial 68.2 (지도 33.1), IN-Rendition 64.4, IN-Sketch 49.6, IN-Corruption(낮을수록 좋음) 33.8.

## Ablation에서 알 수 있는 것
- **마스킹 비율 (Fig. 5)**: 75% 부근이 fine-tuning/linear probing 모두 좋음. linear probing은 비율이 오를수록 크게 상승(54.6 → 73.5), fine-tuning은 40~80%에서 둔감하다. BERT의 15%, 기존 비전 연구의 20~50%보다 훨씬 높다.
- **디코더 깊이 (Table 1a)**: 깊을수록 linear probing 증가(1블록 65.5 → 8블록 73.5), fine-tuning은 거의 무관(84.8~84.9). 해석: 디코더 마지막 층이 복원에 특화되므로 충분한 깊이가 있어야 인코더 표현이 추상적으로 남는다.
- **인코더에 mask token을 넣으면 (Table 1c, Table 2)**: ft 84.2 / lin 59.6으로 나빠지고 FLOPs 3.3배. 사전학습과 배포 시 입력 분포 불일치가 원인으로 설명된다. 벽시계 속도: ViT-L 42.4h → 15.4h (2.8×), 1블록 디코더 11.6h (3.7×), ViT-H는 3.5~4.1×.
- **타깃 (Table 1d)**: 정규화 픽셀 85.4/73.9가 최고, PCA 84.6, dVAE 토큰 85.3/71.6. Table 7에서 정규화 픽셀과 dVAE 토큰은 통계적으로 차이가 없어 **토크나이저가 불필요**하다.
- **증강 (Table 1e)**: crop만으로 충분, color jitter는 오히려 하락(84.3), 증강이 아예 없어도 동작(84.0). 무작위 마스킹이 증강 역할을 한다.
- **마스크 샘플링 (Table 1f)**: random 75% 84.9/73.5가 최고, block 75% 82.8/63.9, grid 75% 84.0/66.0.
- **학습 길이 (Fig. 7)**: 1600 epoch까지 linear probing이 포화하지 않음(MoCo v3는 ViT-L에서 300 epoch에 포화). 인코더가 epoch당 패치의 25%만 보는 점이 학습 비용 이점이다.
- **Partial fine-tuning (Fig. 9)**: 마지막 블록 1개만 튜닝해도 73.5 → 81.0. MAE는 선형 분리성은 낮지만 비선형 특징이 강해서, 1개 이상 블록을 튜닝하면 항상 MoCo v3보다 좋다(4블록에서 격차 2.6%p).

## 한계와 비판적으로 보기
**논문이 인정한 점**: 이미지는 의미 단위로 분해된 신호가 아니라 "기록된 빛"이어서, 무작위 패치 제거나 픽셀 복원이 의미적 단위와 무관하다. 생성 모델 특성상 학습 데이터 편향을 반영하고 존재하지 않는 내용을 만들 수 있다(Broader impacts).

**내 비판**
- 선형 분리성이 낮다. 라벨 없이 바로 쓰는 특징(검색, k-NN 등)이 필요하면 불리하고, 일부라도 fine-tuning이 필요하다.
- 긴 사전학습 일정(800~1600 epoch)을 요구한다. 1 epoch당 빠르다는 것이지 총 학습이 짧다는 뜻은 아니다.
- 비교가 모두 "저자 구현 + 하이퍼파라미터 탐색"에 기반하고 지도 baseline 레시피(Appendix A.2)도 직접 튜닝한 것이라, 공정성은 노력했지만 재현 격차는 남을 수 있다.
- 단일 스케일 vanilla ViT만 검증했다. 계층형 구조(Swin 등)에서는 마스크 토큰 제거가 단순하지 않다(논문은 "advanced networks"를 기대한다고만 언급).
- 의미 수준 주장("holistic 복원 = 의미 학습")은 정성적 가설이다.

## 내 생각 / 더 볼 것
- 핵심 통찰은 "**마스킹 비율이 높을수록 과제가 어려워지는 동시에 인코더 연산이 줄어든다**"는 정렬이다. 정확도와 효율이 같은 방향이라는 점이 스케일 가능성의 근거다.
- 후속 연구(내 지식 기준, 본문에 없음): 시간 축으로 확장한 VideoMAE, 오디오/포인트클라우드 변형, 픽셀 대신 특징을 복원하는 계열, DINOv2의 iBOT식 마스킹 결합 등. DINOv2 개념 정리와 함께 비교해 보면 좋다.
- 관련 직관: LLM의 "토큰을 건너뛰는" 효율화(MoD 등)와도 닿아 있다. 보이는 토큰만 비싼 연산에 쓴다는 아이디어이기 때문.
- 더 볼 것: 원 논문 [35] (Benchmarking detection transfer learning with ViT), 지도 ViT-L/H의 안정적 학습 레시피(Appendix A.2, wd 0.3, β2=0.95, EMA 0.9999).
