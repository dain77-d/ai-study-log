# Toward Foundation Detection Models via Example-Based Grounding in EM-DETR

- 링크: https://arxiv.org/abs/2611.14518 (cs.CV, 2026-11-10)
- 저자: Sheethal Bhat, Bogdan Georgescu, Awais Mansoor, Florin C. Ghesu, Sasa Grbic, Andreas Maier (FAU Erlangen-Nürnberg / Siemens Healthineers)
- 전문 확인: arXiv HTML 버전을 직접 받아 본문 전체(Motivation~Conclusion, Table 1–4, Fig. 1–5 캡션)를 읽고 작성.

## 한 줄 요약
라벨 공간이 서로 다른 의료영상 데이터셋(해부학 vs 병변, CXR vs 유방촬영)을 하나의 검출기로 합치기 위해 (1) teacher–student 의사라벨링으로 label space를 통일한 Grounding DINO(AAFM)와 (2) 클래스별 "예시(exemplar) 임베딩"을 텍스트와 섞어 검출을 유도하는 EM-DETR 기반 foundation 모델(EM-FM)을 제안하고, CXR 평균 mAP50을 baseline 0.369 → 0.567로 올렸다.

## 배경: 수업에서 배운 것과의 연결
- 수업의 **DETR 계열 검출**(set prediction, object query, cross-attention decoder)이 그대로 뼈대다. 여기서 쓰는 Grounding DINO는 DINO(denoising anchor box DETR) + 텍스트 grounding 사전학습 모델이다.
- **자기지도/대조학습**: GLIP·Grounding DINO·OWL-ViT는 이미지 영역 임베딩과 텍스트 임베딩을 contrastive하게 정렬해 open-vocabulary 검출을 한다(Sec. 1). 이 논문의 문제의식은 "의료에는 이런 대규모 image–text grounding 데이터가 없다"는 점이다.
- **Swin Transformer**를 frozen 백본으로 쓰는 부분(Sec. 3)은 hierarchical ViT의 직접 응용이다.
- **Teacher–student / pseudo-labeling**은 semi-supervised, self-training 계열 아이디어이며, 여기서는 "누락된 클래스 라벨 채우기"라는 용도로 쓰인다.

## 문제 설정
- 의료 병변 검출은 주석이 희소하고, 데이터셋마다 라벨 정의가 다르다(Sec. 1). 해부학(심장, 폐) 주석 데이터와 이상 소견 주석 데이터는 **클래스가 겹치지 않으면서 시각적 특징은 비슷**해, 단순히 합쳐 학습하면 **catastrophic forgetting**으로 분류·검출 성능이 떨어진다(Sec. 3).
- 실제로 데이터셋을 naive하게 합치면 pneumothorax 분류 AUC가 0.75로, FROC 민감도(0.5 FP)가 0.18로 떨어진다고 보고한다(Sec. 4.2).
- 목표: 여러 modality(CXR, mammography)의 이질적 데이터를 통합한 "foundation" 검출 모델.

## 방법
### 1) AAFM: Anatomy–Abnormality Foundation Model (Grounding DINO 기반, Fig. 1)
1. 각 데이터셋 𝒜, ℬ, 𝒞에서 각자의 라벨로 개별 모델 M_A, M_B, M_C를 학습.
2. 각 모델이 teacher가 되어 **다른 데이터셋에서 자신이 아는 클래스**를 예측, 신뢰도가 클래스별 임계값 τ_c 이상인 예측만 weak annotation으로 채택. τ_c는 클래스 c의 ROC 곡선에서 **민감도 95%** 지점으로 설정한다(Sec. 3, 인용 [2]).
3. 해부학 예측은 임계값 없이 이미지·클래스당 top-1을 선택하되, 박스 크기와 위치가 이미지 대비 지나치게 크거나 작은 것은 걸러낸다. 구현 세부로 teacher 점수 0.8 미만, 정답 평균 크기 대비 50% 이상 벗어난 예측은 제외(Sec. 4.1).
4. 모든 데이터셋이 𝒞의 전체 클래스에 대한 주석을 갖도록 반복한 뒤, strong+weak 주석을 모두 사용해 최종 모델(AAFM)을 학습. 방식 자체는 Zhao et al.(ECCV 2020)의 unified label space 접근을 가져온 것이다.

### 2) EM-FM: EM-DETR 기반 multi-domain foundation 모델 (Fig. 2, 3)
EM-DETR은 저자들의 이전 연구(MICCAI 2025, Exemplar Med-DETR)로, Grounding DINO 위에 **클래스별 exemplar 임베딩**을 텍스트 임베딩과 interleave해 디코더가 "텍스트 + 시각 예시"로 검출 대상을 찾도록 한다.
- frozen Swin 백본에서 패치 임베딩 X′와 위치 인코딩 P′ 추출. 클래스 k의 주석 영역 토큰 X_k를 골라
  - H_k = X_k + a_k × P′  (식 1, a_k는 학습 가능한 스칼라)
  - q_k = F(concat(ct_k, ce_k, H_k)) + ct_k + ce_k  (식 2, F는 학습되는 Transformer 모듈, ct_k/ce_k는 클래스별 learnable token/position embedding)
- 학습 안정화를 위해 q_k의 이동 평균을 **memory bank**에 e_k로 저장. 추론 시에는 주석이 없으므로 저장된 e_k로 검출을 유도(Fig. 2의 점선).
- 추가 손실 L_contrast(클래스 exemplar e_k 간 orthogonality)와 L_feat(디코더 top proposal이 해당 e_k와 정렬)를 사용.
- **2단계(iterative) 학습**(Fig. 3): Stage 1은 데이터셋 ℬ, 𝒞, ℳ(mammography)의 전체 주석으로 encoder/decoder를 사전학습. Stage 2는 클래스별 foreground vs background 소규모 데이터로 정제. background는 정상 영상에서, 훈련 데이터의 병변 위치 분포를 이용해 선택한다.
- EM-FM에서는 해부학 데이터 𝒜를 제외한다. 다중 도메인 결합으로 주석이 충분히 많아져 보조 해부학 감독의 필요가 줄었다는 설명이다(Sec. 3).

## 실험 설정
- 데이터(Sec. 2): 𝒜 = 심장·폐 주석 CXR 15,000장(좌/우 폐 분리), ℬ = 16개 소견 박스 주석 16,953장(비공개), 𝒞 = VinDr-CXR(18,000장, 학습 15,000/테스트 3,000, 22개 로컬 라벨), ℳ = VinDr-Mammo(학습 15,000장, 절반이 정상, 테스트 4,000장).
- 평가 세트: 전문가 gold-standard 이진 라벨. atelectasis·consolidation 각 333장, pleural effusion 331장, pneumothorax 412장(환자 중복 없음). Table 1에 양성 비율 있음(예: atelectasis 학습 양성 128개로 0.07%).
- 비교 대상: RPS(상용 Reference Product Solution, ResNet-101 FCOS, 1억 장 자기지도 사전학습 + NMS 사용, [6]), Baseline(Grounding DINO, ℬ만 학습), AAFM, EM-DETR(단일 데이터셋), EM-FM.
- 지표: image-level AUC(클래스별 최대 확률), mAP50(MMDetection의 COCO 프로토콜), FROC(중심 거리 기반 민감도, 0.5 FP에서의 값).
- 학습: A100 40GB 4장, MMDetection, Swin-L, GPU당 batch 1, lr 0.0008, CXR용 augmentation(auto-contrast, sharpness, horizontal flip), "right lung/left lung"을 텍스트 어휘에 추가, 최대 25 epoch, 5회 반복 후 mAP50 기준 상위 5개 체크포인트의 평균을 보고(Sec. 4.1). 유방촬영은 어두운 배경을 crop하고 주석을 재계산.

## 결과
**분류 AUC (Table 2, 표준편차 < ±0.005)**

| Finding | RPS | Baseline | AAFM | EM-FM |
|---|---|---|---|---|
| Consolidation | 0.932 | 0.926 | 0.943* | 0.921 |
| Atelectasis | 0.949 | 0.959 | 0.974* | 0.932 |
| Pleural effusion | 0.993 | 0.994 | 0.993 | 0.993 |
| Pneumothorax | 0.975 | 0.978 | 0.978 | 0.968 |
| Average | 0.962 | 0.959 | 0.972* | 0.954 |

AAFM이 평균 AUC에서 RPS 대비 약 1%p 향상(p<0.05, Sec. 4.2). 반대로 EM-FM은 평균 0.954로 RPS보다 낮다.

**검출 mAP50 (Table 3, 표준편차 < ±0.1)**

| Finding | Baseline | AAFM | EM-DETR | EM-FM |
|---|---|---|---|---|
| Consolidation | 0.450 | 0.386* | 0.539* | 0.596* |
| Atelectasis | 0.363 | 0.366 | 0.346 | 0.363 |
| Pleural effusion | 0.244 | 0.240 | 0.715* | 0.756* |
| Pneumothorax | 0.419 | 0.444* | 0.508* | 0.556* |
| CXR 평균 | 0.369 | 0.359 | 0.527 | 0.567* |
| Mammography Mass | 0.583 | — | 0.699* | 0.721* |

본문 서술: EM-FM은 baseline 대비 consolidation +14.6, pleural effusion +51.2, pneumothorax +13.7%p, 평균 +19.9%p(0.567 vs 0.369). EM-DETR 대비로는 CXR 소견에서 2–6%p, mammography에서 2.2%p 우수.

**FROC, 0.5 FP에서의 민감도 (Table 4, 표준편차 < ±0.01)**

| Finding | RPS | Baseline | AAFM | EM-FM |
|---|---|---|---|---|
| Consolidation | 0.900 | 0.840 | 0.740 | 0.891 |
| Atelectasis | 0.950 | 0.970 | 0.940 | 0.896 |
| Pleural Effusion | 0.997 | 0.987 | 0.987 | 0.987 |
| Pneumothorax | 0.970 | 0.945 | 0.973 | 0.935 |
| Average | 0.954 | 0.936 | 0.910 | 0.927 |

RPS가 평균 0.954로 가장 높고 EM-FM(0.927)은 경쟁력 있는 수준이라고 서술. 수렴 속도(Fig. 5): pneumothorax mAP50의 epoch별 곡선에서 EM-FM이 baseline·EM-DETR보다 빠르고 안정적으로 수렴.

## Ablation에서 알 수 있는 것
정식 ablation 표는 없고, 본문에서 간접적으로 읽을 수 있는 비교만 있다.
- **naive dataset 합치기 vs. teacher–student**: naive 결합 시 pneumothorax AUC 0.75, 민감도 0.18로 붕괴(Sec. 4.2). 의사라벨링 통합(AAFM)은 이를 AUC 0.978, 민감도 0.973까지 회복. forgetting 완화 효과가 가장 명확히 드러나는 비교다. 다만 수치는 본문 서술이며 별도 표로 제공되지는 않는다.
- **AAFM vs. EM-DETR/EM-FM**: AAFM은 AUC에는 좋지만 mAP50은 baseline 수준(0.359 vs 0.369)이다. 저자들은 teacher 임계값이 분류 최적화로 정해진 점(95% 민감도)과 Grounding DINO contrastive 학습이 선택 클래스 집합에 의존하는 점을 이유로 든다. 즉 분류용 threshold가 localization엔 맞지 않는다는 해석.
- **EM-DETR → EM-FM**: 다중 도메인 데이터를 추가하면 단일 데이터 EM-DETR 대비 mAP50이 추가로 오른다(0.527 → 0.567).
- 해부학 데이터 𝒜 제외 결정은 근거 실험이 제시되지 않았다.

## 한계와 비판적으로 보기
**논문이 인정한 것**: atelectasis는 개선이 없다. 저자들은 consolidation/distalectasis와 임상적으로 겹치고 서로 병리 스펙트럼 상의 다른 단계일 수 있어 데이터셋 간 라벨이 노이즈를 띤다고 설명한다. 향후 더 많은 소견·데이터셋으로 일반화를 검증하겠다고 결론에서 밝힘.

**내 비판**
- 이름은 "foundation"이지만 모달리티는 CXR과 mammography 두 가지, 평가 소견도 CXR 4개+mass 1개뿐이다. 새로운 클래스를 학습 없이 검출하는 능력(진짜 open-set/zero-shot)의 평가는 없다.
- 헤드라인 주장이 지표마다 갈린다. AUC에서는 AAFM이 좋고 EM-FM은 오히려 RPS보다 낮으며, FROC에서는 RPS가 여전히 최고다. mAP50 개선만 EM-FM이 크다. "SOTA"를 말할 때 어떤 지표·어떤 모델인지 구분해서 읽어야 한다.
- 비교가 공정하지 않을 수 있다: RPS는 1억 장 사전학습, ResNet-101이고 baseline/AAFM/EM-FM은 Swin-L이라 백본·데이터 규모가 다르다(Table 2의 ε/† 표기). 또 평가셋이 330~410장으로 작고 atelectasis 양성이 83개뿐이라 통계적 변동이 클 수 있다(다만 5회 반복·p<0.05 표시는 있음).
- 데이터 ℬ와 RPS가 비공개라 재현성이 제한적이다. 결과가 "상위 5개 체크포인트를 mAP50 기준으로 선택"한 평균이라는 점도, 선택이 평가 지표에 맞춰진 점에서 약간 낙관적일 수 있다(validation/test 분리 방식은 본문에서 자세히 설명되지 않음).
- pleural effusion mAP50이 baseline 0.244 → EM-DETR 0.715로 폭증하는 부분은 인상적이지만, baseline이 contrastive 학습으로 불안정하다는 설명(Fig. 5 논의) 외에 원인 분석이 부족하다. baseline이 그냥 덜 튜닝되었을 가능성도 배제하기 어렵다.

## 내 생각 / 더 볼 것
- 핵심 교훈은 "label space가 다른 데이터를 합칠 때 teacher의 가짜 라벨로 빈칸을 메운다"는 고전적 해법이 DETR류 open-vocabulary 모델에서도 유효하다는 점이다. 임계값을 어떻게 정하느냐(여기서는 95% 민감도)가 localization 품질과 충돌한다는 관찰은 실무적으로 유용하다.
- 텍스트가 모호한 의료 영역에서 "텍스트 + 시각 exemplar" 쿼리로 검출 대상을 지정하는 것은, 자연영상 open-vocabulary 검출의 visual prompt/few-shot 검출과 같은 흐름이다. 
- 더 볼 것: 이전 논문 EM-DETR(arXiv:2507.19621), Zhao et al. "Object detection with a unified label space from multiple datasets"(ECCV 2020), Grounding DINO(ECCV 2024), 그리고 자연영상의 visual-prompt 기반 검출과의 비교.
