# Direct Preference Optimization: Your Language Model is Secretly a Reward Model

- 링크: https://arxiv.org/abs/2305.18290
- 저자: Rafael Rafailov, Archit Sharma, Eric Mitchell, Christopher D. Manning, Stefano Ermon, Chelsea Finn (Stanford)
- 발표: arXiv 2023-05-29 (v1), NeurIPS 2023

> 왜 이 논문인가: NeurIPS 2023 **Outstanding Main Track Runner-up**로 선정됨(NeurIPS 공식 블로그 "Announcing the NeurIPS 2023 Paper Awards"에서 확인, 2026-11-11 검색). 인용 수는 Semantic Scholar API에 접속하지 못해 확인하지 못했으므로 적지 않는다. 이후 오픈 모델 정렬(alignment)의 기본 레시피가 된 방법이라 현대 LLM 후처리를 이해하려면 한 번은 유도 과정을 직접 따라가 봐야 한다.

## 한 줄 요약
RLHF의 "KL 제약 보상 최대화" 문제는 최적해가 닫힌 형태(closed form)로 나오므로, 보상을 정책의 로그비 `β log π/π_ref`로 **변수 치환**하면 Bradley-Terry 선호 손실이 정책에 대한 단순한 이진 교차엔트로피가 된다. 보상 모델 학습과 PPO 루프가 모두 사라진다.

## 배경: 수업에서 배운 것과의 연결
- 수업의 LLM 파트에서 SFT → 보상 모델 → PPO로 이어지는 RLHF 파이프라인을 봤다면, 이 논문은 그 3단계 중 뒤 2단계를 하나의 지도학습 손실로 합친 것이다.
- 확산 모델/VAE에서 익힌 감각과도 닿아 있다. 우리는 "정규화 상수를 직접 못 구하는 분포"를 다루는 방법(ELBO, score matching 등)을 배웠는데, DPO는 **두 응답의 차이를 취하면 분배함수 Z(x)가 상쇄**된다는 점을 이용해 같은 문제를 우회한다.
- Self-attention/Transformer 쪽에서는 새로 필요한 것이 없다. 정책 하나, 고정된 참조 모델 하나가 전부이고 모델 구조는 그대로 쓴다.

## 문제 설정
RLHF(Sec. 3)는 세 단계다.
1. **SFT**: 고품질 데이터로 `π^SFT` 학습.
2. **보상 모델링**: `π^SFT`로 응답 쌍 (y1, y2)을 뽑고 사람이 선호 `y_w ≻ y_l | x`를 라벨링. 잠재 보상 r*를 가정한 Bradley-Terry 모델:
   `p*(y1 ≻ y2 | x) = exp(r*(x,y1)) / (exp(r*(x,y1)) + exp(r*(x,y2)))` (Eq. 1)
   보상 모델은 `L_R = -E[log σ(r_φ(x,y_w) - r_φ(x,y_l))]` (Eq. 2)로 최대우도 학습한다.
3. **RL 미세조정**: `max_π E[r_φ(x,y)] - β D_KL[π(y|x) || π_ref(y|x)]` (Eq. 3). 텍스트 생성은 이산적이라 미분이 안 되어 PPO 등으로 푼다. 보상은 `r_φ - β(log π_θ - log π_ref)`로 구성한다.

논문이 지적하는 문제: 여러 LM을 학습해야 하고, 학습 루프 안에서 정책으로부터 샘플링해야 해서 계산 비용이 크고 복잡하다(Sec. 1). 목표는 **같은 목적함수를 RL 없이** 푸는 것이다.

## 방법
### 1) 최적 정책의 닫힌 형태
임의의 보상 r에 대해 Eq. 3의 최적해는 (Appendix A.1)

`π_r(y|x) = (1/Z(x)) · π_ref(y|x) · exp(r(x,y)/β)` (Eq. 4), `Z(x) = Σ_y π_ref(y|x) exp(r(x,y)/β)`

Z(x)는 모든 가능한 응답에 대한 합이라 추정하기 비싸다. 양변에 로그를 취해 보상을 정책으로 표현하면

`r(x,y) = β log (π_r(y|x)/π_ref(y|x)) + β log Z(x)` (Eq. 5)

### 2) 변수 치환과 Z(x) 상쇄
Bradley-Terry는 보상의 **차이**에만 의존한다(`σ(r*(x,y1) - r*(x,y2))`). Eq. 5를 대입하면 `β log Z(x)` 항이 두 보상에서 똑같이 나와 상쇄되고

`p*(y1 ≻ y2|x) = 1 / (1 + exp(β log π*(y2|x)/π_ref(y2|x) - β log π*(y1|x)/π_ref(y1|x)))` (Eq. 6)

### 3) DPO 손실
정책 π_θ를 이 선호 모델의 최대우도로 학습한다.

`L_DPO(π_θ; π_ref) = -E_{(x,y_w,y_l)~D}[ log σ( β log π_θ(y_w|x)/π_ref(y_w|x) - β log π_θ(y_l|x)/π_ref(y_l|x) ) ]` (Eq. 7)

보상 모델을 따로 두지 않고, 정책 자체가 **암묵적 보상** `r̂_θ(x,y) = β log π_θ(y|x)/π_ref(y|x)`를 정의한다. 이것이 제목의 "Your LM is secretly a reward model"이다. Plackett-Luce 버전도 Appendix A.3에서 유도한다.

### 4) 그래디언트가 하는 일
`∇_θ L_DPO = -β E[ σ(r̂_θ(x,y_l) - r̂_θ(x,y_w)) · (∇ log π(y_w|x) - ∇ log π(y_l|x)) ]`

- y_w의 로그우도는 올리고 y_l은 내린다.
- 가중치 `σ(r̂(y_l) - r̂(y_w))`는 **암묵적 보상이 순서를 틀리게 매긴 샘플**에 더 크다. 논문은 이 가중치가 없는 단순 버전(unlikelihood)은 모델이 퇴화한다고 보고한다(Sec. 4, Appendix Table 3: 요약 같은 복잡한 과제에서 의미 있는 응답을 못 만든다).

### 5) 이론 (Sec. 5)
- 보상 함수 r, r'가 `r - r' = f(x)`이면 같은 클래스(Definition 1). 같은 클래스는 같은 선호 분포(Lemma 1)와 같은 최적 정책(Lemma 2)을 유도한다.
- **Theorem 1**: 가벼운 가정 아래, Plackett-Luce/Bradley-Terry와 일치하는 모든 보상 클래스는 `r = β log π/π_ref`로 표현 가능하다. 즉 이 재매개화가 표현력을 잃지 않는다. 합이 1이 되는 `Σ_y π_ref exp(r/β) = 1` 제약(Eq. 9)이 클래스 안에서 대표 원소를 고르는 역할을 한다.
- **Actor-critic 불안정성 진단(Sec. 5.2)**: PPO 목적(Eq. 10)에는 π_ref의 소프트 가치 함수에 해당하는 정규화 항이 들어간다. 최적해는 안 바꾸지만 없으면 정책 그래디언트 분산이 커진다. 기존에는 학습된 가치 함수나 사람 응답 기반 baseline(1-샘플 몬테카를로 추정)으로 대응했는데, DPO의 보상 매개화는 baseline이 필요 없다.

### 6) 구현 세부 (Appendix B)
- 파이프라인: π_ref로 프롬프트당 두 응답을 뽑아 선호 라벨링(또는 공개 선호 데이터셋 재사용) → Eq. 7 최소화.
- π_ref는 `π_SFT`로 초기화. SFT 모델이 없으면 선호 응답 y_w의 우도를 최대화해 π_ref를 만든다.
- 기본 하이퍼파라미터: β=0.1, 배치 64, RMSprop, lr 1e-6, 150 step 선형 워밍업. TL;DR 요약만 β=0.5.
- PyTorch 구현은 약 10줄: `losses = -F.logsigmoid(beta * (pi_logratios - ref_logratios))`.

## 실험 설정
- **통제된 감성 생성(IMDb)**: x는 리뷰 앞부분(2~8 토큰), 긍정 리뷰 생성. 정답 보상으로 `siebert/sentiment-roberta-large-english`를 쓰고 GPT-2-large를 SFT. 프롬프트 25,000개에 대해 4개 완성을 뽑아 프롬프트당 6개 선호 쌍 생성(Appendix C.1).
- **요약(Reddit TL;DR)**: Stiennon 등의 사람 선호 데이터, SFT는 GPT-J 기반 공개 체크포인트.
- **단일 턴 대화(Anthropic HH)**: 170k 대화. 공개 SFT 모델이 없어 Pythia-2.8B를 선호 응답으로 미세조정해 π_ref로 사용.
- **평가**: 감성은 (실제 보상, 참조 모델과의 KL) 프런티어. 요약/대화는 GPT-4 승률(요약은 테스트셋 참조 요약, 대화는 테스트셋 선호 응답 대비). GPT-4 신뢰성은 사람 평가로 검증(Sec. 6.4).
- **베이스라인**: zero-shot(GPT-J)/2-shot(Pythia-2.8B) 프롬프팅, SFT, Preferred-FT, Unlikelihood, PPO(학습된 보상), PPO-GT(정답 보상 오라클), Best-of-N.

## Ablation에서 알 수 있는 것
전통적 의미의 ablation 표는 없고, 아래가 사실상 그 역할이다.
- **가중치 제거(Unlikelihood)**: DPO의 동적 가중치 없이 y_w↑, y_l↓만 하면 요약/대화에서 의미 없는 출력이 나온다(Appendix Table 3). 이 가중치(암묵적 보상 오류에 비례)가 핵심이라는 근거.
- **PPO vs PPO-GT**: 보상 모델 품질 문제가 아니라 최적화 자체의 효율 문제임을 보여준다(정답 보상을 줘도 DPO 프런티어를 못 넘음).
- **Best-of-N의 N**: N=1,4,16,64,128 중 약 64~128에서 포화 → Best-of-128을 "PPO급 성능의 대략적 대용"으로 쓴 근거.
- **온도 강건성**: DPO는 샘플링 온도에 덜 민감하고, 학습 중 승률이 안정적이다(Fig. 3 우).

## 한계와 비판적으로 보기
**논문이 밝힌 한계 (Sec. 7)**
- OOD 일반화가 명시적 보상 모델 방식에 비해 어떤지 더 연구가 필요하다(CNN/DM 결과는 "초기 증거").
- 보상 과최적화(reward over-optimization)가 DPO에서 어떻게 나타나는지 불명확하다. Fig. 3 우측의 약간의 성능 하락이 그 사례일 수 있다.
- 최대 6B 파라미터까지만 평가했다.
- GPT-4 승률이 프롬프트에 따라 달라진다.

**내 비판**
- 오프라인 선호 쌍에 의존한다. 학습 중 정책이 바뀌어도 데이터는 π_SFT에서 뽑힌 그대로이므로 분포 이동이 생길 수 있다. 논문도 π_ref를 데이터 생성 분포에 맞추려고 신경 쓴다(Sec. 4).
- 평가가 GPT-4 승률 중심이고, 대화에서는 "참조 응답"이 데이터셋의 선호 응답이라 절대적 품질 척도로는 약하다. 부록 Table 9, 10에서 보듯 GPT-4 판정 자체가 틀리기도 하고, DPO 출력이 장황하며 사실 오류를 낼 수 있다.
- PPO 대화 베이스라인은 공개 체크포인트를 그대로 썼고 "base보다 나은 설정을 못 찾았다"고 했으므로, PPO를 충분히 튜닝한 비교라고 보긴 어렵다. 요약 과제의 PPO 대비 우위(61% vs 57%)는 크지 않다.
- 이 논문의 이론은 Bradley-Terry 가정에 기댄다. 실제 사람 선호가 이 모델을 따르지 않으면 보장은 약해진다.

## 내 생각 / 더 볼 것
- 핵심 교훈은 "RL 문제처럼 보여도 최적해가 닫힌 형태면 지도학습으로 바꿀 수 있다"는 것이다. 구현이 10줄이라 비용 대비 효과가 크고, 그래서 널리 채택됐다고 본다. (이후 연구가 어떤 변형들을 냈는지는 이 논문에 없는 내용이므로, 아래는 읽을 거리 후보로만 적는다.)
- 더 볼 것: IPO, KTO, SimPO 같은 DPO 변형들, 온라인/반복(iterative) DPO, GRPO를 포함한 RL 기반 추론 학습과의 비교. DPO의 한계로 지적된 "오프라인 데이터 분포 문제"가 이들에서 어떻게 다뤄지는지 확인해 볼 만하다.
- 직접 해볼 것: 장난감 토큰 분포에서 `π*` 닫힌 해와 DPO 학습 결과를 비교해 Eq. 4~7이 맞는지 수치로 확인.
