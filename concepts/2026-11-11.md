# 경사 하강법 (Gradient Descent)

## 직관

산 위에서 안개 속에 서 있다고 상상해 보자. 지도는 없지만 발밑의 경사는 느낄 수 있다.
가장 가파르게 내려가는 방향으로 한 걸음씩 내딛으면 결국 골짜기(손실이 작은 곳)에 도착한다.
경사 하강법은 이 과정을 그대로 수학으로 옮긴 것이다.

- **손실 함수(loss)**: 모델이 얼마나 틀렸는지를 숫자 하나로 나타낸 것
- **기울기(gradient)**: 파라미터를 조금 바꿨을 때 손실이 얼마나 변하는지
- **학습률(learning rate)**: 한 걸음의 크기

기울기의 반대 방향으로 가면 손실이 줄어든다. 신경망 학습의 거의 모든 것이 이 아이디어 위에 서 있다.

## 수식

파라미터 θ, 손실 L(θ), 학습률 η일 때:

```
θ ← θ - η · ∇L(θ)
```

선형 회귀 `ŷ = w·x + b`, 손실이 평균제곱오차(MSE)이면:

```
L = (1/n) Σ (w·xᵢ + b - yᵢ)²
∂L/∂w = (2/n) Σ (w·xᵢ + b - yᵢ) · xᵢ
∂L/∂b = (2/n) Σ (w·xᵢ + b - yᵢ)
```

실제 딥러닝에서는 전체 데이터 대신 일부(미니배치)로 기울기를 추정하는 SGD를 주로 쓴다.

## 코드

표준 라이브러리만 사용한 예제. y = 3x + 2 에 노이즈를 섞은 데이터에서 w, b를 찾는다.

```python
import random

random.seed(0)
X = [random.uniform(-1, 1) for _ in range(100)]
y = [3 * x + 2 + random.gauss(0, 0.1) for x in X]

w, b, lr = 0.0, 0.0, 0.1
n = len(X)
for step in range(200):
    errs = [w * x + b - t for x, t in zip(X, y)]
    loss = sum(e * e for e in errs) / n
    gw = 2 * sum(e * x for e, x in zip(errs, X)) / n
    gb = 2 * sum(errs) / n
    w -= lr * gw
    b -= lr * gb
    if step % 50 == 0:
        print(f"step {step:3d} loss={loss:.4f} w={w:.3f} b={b:.3f}")
print(f"최종: w={w:.3f}, b={b:.3f} (정답: 3, 2)")
```

실행 결과(직접 실행해 확인함):

```
step   0 loss=8.7768 w=0.252 b=0.503
step  50 loss=0.0146 w=2.814 b=2.042
step 100 loss=0.0084 w=2.946 b=2.011
step 150 loss=0.0084 w=2.954 b=2.009
최종: w=2.954, b=2.009 (정답: 3, 2)
```

## 자주 하는 실수

- **학습률이 너무 크다**: 골짜기를 넘나들며 손실이 발산한다. 너무 작으면 학습이 끝없이 느리다.
- **부호 실수**: `θ - η·∇L` 이어야 한다. 더하면 손실이 오히려 커진다.
- **입력 스케일을 무시한다**: 특성마다 크기 차이가 크면 손실 표면이 길쭉해져 수렴이 느려진다. 정규화가 도움이 된다.
- **기울기 계산을 검증하지 않는다**: 수치 미분(작은 값 h로 차이를 계산)과 비교하면 버그를 잡기 쉽다.
- **"전역 최솟값에 도달한다"고 믿는다**: 신경망의 손실 표면은 비볼록이라 보장되지 않는다. 실전에서는 충분히 좋은 지점이면 된다.
