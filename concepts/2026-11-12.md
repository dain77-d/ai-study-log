# DETR와 set prediction: Hungarian matching으로 NMS 없는 검출

> 원문: [End-to-End Object Detection with Transformers](https://arxiv.org/abs/2005.12872) — Carion, Massa, Synnaeve, Usunier, Kirillov, Zagoruyko (Facebook AI), arXiv 2020-05 (ECCV 2020). 이 글은 arXiv v3 PDF 전문(약 8만 자)을 추출해 읽고 정리했다. 아래 수치와 표 번호는 모두 그 본문 기준이다.

## 왜 나왔나

수업에서 배운 detection(Faster R-CNN, YOLO, SSD 계열)은 겉으로는 end-to-end처럼 보이지만 사실 사람 손이 많이 들어간 파이프라인이다.

- **초기 추정(prior)에 의존**: two-stage는 proposal, single-stage는 anchor나 grid 중심점을 기준으로 예측한다. 논문은 최종 성능이 이 초기 추정을 어떻게 잡느냐에 크게 좌우된다고 지적한다(Sec. 2.3).
- **many-to-one 할당 + NMS**: GT 하나에 여러 anchor/proposal을 양성으로 할당(IoU 임계값 같은 규칙)하니 중복 예측이 생기고, 이를 NMS라는 후처리로 지운다. 학습 목표(중복 허용)와 추론 목표(중복 제거)가 어긋난다.

DETR의 질문은 이렇다. **"검출을 그냥 집합(set) 예측 문제로 보면 안 되나?"** 이미지 하나를 넣으면 고정 크기 N개의 (클래스, 박스)를 한 번에 내놓고, 정답 집합과 **일대일로** 맞춰 loss를 주면 anchor도 NMS도 필요 없다. 핵심은 (1) 예측과 정답의 일대일 매칭을 정의하는 loss, (2) 예측들끼리 관계를 볼 수 있는 구조(Transformer)다.

## 핵심 아이디어

**구조 (Sec. 3.2, Fig. 2)**
1. CNN backbone이 `C x H x W` 특징맵을 만든다(C=2048, H,W = H0/32, W0/32). 1x1 conv로 d차원으로 줄이고 공간을 펴서 `HW`개의 토큰으로 만든다.
2. **Transformer encoder**: 토큰 간 전역 self-attention. 순서 정보가 없으니 고정 sine 위치 인코딩을 매 attention 층의 입력에 더한다.
3. **Transformer decoder**: 입력은 이미지가 아니라 **학습되는 임베딩 N개(object queries)**. 각 층에서 queries끼리 self-attention, encoder 출력에 cross-attention을 한다. autoregressive가 아니라 N개를 **병렬** 디코딩한다.
4. 각 출력 임베딩을 공유 FFN(3층 MLP + 선형층)에 넣어 정규화된 (cx, cy, w, h)와 클래스(+ "no object" ∅)를 낸다.

**일대일 매칭 (Sec. 3.1)**: N은 이미지당 실제 객체 수보다 훨씬 크게 잡고(실험은 N=100), GT도 ∅로 N개까지 패딩한다고 본다. 예측과 GT 사이 최소 비용 순열을 Hungarian algorithm으로 구한 뒤, 매칭된 쌍에만 box loss를 준다. 매칭되지 않은 슬롯은 ∅ 클래스가 되도록 학습된다. 이 "매칭 = 일대일"이 중복 예측을 loss 수준에서 벌한다. 그래서 decoder의 self-attention이 "내 옆 슬롯이 이미 이 물체를 잡았다"를 보고 중복을 억제하는 법을 배우게 된다.

## 수식

최적 매칭 (논문 식 1):

$$\hat\sigma = \arg\min_{\sigma\in\mathfrak S_N}\sum_{i}^{N}\mathcal L_{match}(y_i,\hat y_{\sigma(i)})$$

매칭 비용: 정답 $y_i=(c_i,b_i)$, $b_i\in[0,1]^4$ 에 대해

$$\mathcal L_{match}=-\mathbb 1_{\{c_i\neq\varnothing\}}\hat p_{\sigma(i)}(c_i)+\mathbb 1_{\{c_i\neq\varnothing\}}\mathcal L_{box}(b_i,\hat b_{\sigma(i)})$$

Hungarian loss (식 2):

$$\mathcal L_{Hungarian}=\sum_{i=1}^{N}\Big[-\log\hat p_{\hat\sigma(i)}(c_i)+\mathbb 1_{\{c_i\neq\varnothing\}}\mathcal L_{box}(b_i,\hat b_{\hat\sigma(i)})\Big]$$

박스 loss: $\mathcal L_{box}=\lambda_{iou}\mathcal L_{iou}+\lambda_{L1}\lVert b_i-\hat b_{\sigma(i)}\rVert_1$ (GIoU 사용, 배치 내 객체 수로 정규화).

디테일 몇 가지가 실제로 중요하다.
- **매칭 비용에는 log-prob가 아닌 확률 $\hat p$를 쓴다.** 박스 항과 스케일을 맞추기 위함이고, 실험적으로 더 좋았다고 한다(Sec. 3.1). 반면 loss 쪽 분류항은 일반적인 $-\log p$.
- **∅ 클래스 항은 가중치 1/10**로 낮춰 클래스 불균형을 보정한다(Faster R-CNN의 positive/negative subsampling에 해당).
- **직접 박스 회귀**를 하므로 $\ell_1$만 쓰면 큰 박스와 작은 박스의 스케일이 다르다. 스케일 불변인 GIoU를 섞는다. 하이퍼파라미터는 $\lambda_{L1}=5,\ \lambda_{iou}=2$ (부록 A.4).
- **Auxiliary decoding loss**: 모든 decoder 층 뒤에 같은 FFN과 Hungarian loss를 붙인다(Sec. 3.2).
- 추론 시 ∅로 예측된 슬롯은 버리는 대신 두 번째로 높은 클래스로 덮어써서 AP가 약 2 올랐다고 한다(Sec. 4).

## 코드

numpy만 쓴 최소 예제다. 비용 행렬(분류 확률 + L1 + GIoU)을 만들고, 일대일 최적 매칭(작은 N이라 brute force; 실제 구현은 $O(N^3)$ Hungarian)과 "각 GT가 가장 싼 슬롯을 고르는" greedy를 비교한 뒤, Hungarian loss를 계산한다. 마지막 블록은 greedy가 유일성을 깨는 경우다.

```python
import itertools
import numpy as np

def cxcywh_to_xyxy(b):
    cx, cy, w, h = b
    return np.array([cx - w/2, cy - h/2, cx + w/2, cy + h/2])

def giou(a, b):
    a, b = cxcywh_to_xyxy(a), cxcywh_to_xyxy(b)
    ix1, iy1 = max(a[0], b[0]), max(a[1], b[1])
    ix2, iy2 = min(a[2], b[2]), min(a[3], b[3])
    inter = max(ix2 - ix1, 0) * max(iy2 - iy1, 0)
    area = lambda x: (x[2]-x[0]) * (x[3]-x[1])
    union = area(a) + area(b) - inter
    iou = inter / union
    hull = (max(a[2], b[2]) - min(a[0], b[0])) * (max(a[3], b[3]) - min(a[1], b[1]))
    return iou - (hull - union) / hull

def cost_matrix(probs, pboxes, gt_cls, gt_boxes, w_cls=1.0, w_l1=5.0, w_giou=2.0):
    # C[i, j] = cost of assigning prediction i to ground-truth j (Eq. 1 of the paper)
    N, M = len(probs), len(gt_cls)
    C = np.zeros((N, M))
    for i in range(N):
        for j in range(M):
            C[i, j] = (-w_cls * probs[i, gt_cls[j]]
                       + w_l1 * np.abs(pboxes[i] - gt_boxes[j]).sum()
                       - w_giou * giou(pboxes[i], gt_boxes[j]))
    return C

def optimal_match(C):
    # exact min-cost one-to-one matching; brute force is fine for tiny N.
    # (real code uses the Hungarian algorithm, O(N^3))
    N, M = C.shape
    best, best_cost = None, np.inf
    for perm in itertools.permutations(range(N), M):
        cost = sum(C[p, j] for j, p in enumerate(perm))
        if cost < best_cost:
            best, best_cost = perm, cost
    return {j: p for j, p in enumerate(best)}

def greedy_match(C):
    # "each GT takes its cheapest prediction" - no uniqueness constraint
    return {j: int(C[:, j].argmin()) for j in range(C.shape[1])}

rng = np.random.default_rng(0)
num_classes = 3                       # class index num_classes = "no object"
gt_cls = [0, 1]
gt_boxes = np.array([[0.30, 0.30, 0.20, 0.20], [0.70, 0.60, 0.30, 0.40]])
N = 5
# slots 0 and 1 both fire on GT 0 (duplicates, as in a model before training),
# slot 2 is on GT 1, slots 3,4 are junk
pboxes = np.array([[0.31, 0.30, 0.20, 0.20], [0.30, 0.31, 0.21, 0.19],
                   [0.70, 0.62, 0.30, 0.40], [0.50, 0.50, 0.10, 0.10],
                   [0.90, 0.10, 0.10, 0.10]])
logits = rng.normal(size=(N, num_classes + 1))
logits[[0, 1], 0] += 4; logits[2, 1] += 4
probs = np.exp(logits) / np.exp(logits).sum(1, keepdims=True)

C = cost_matrix(probs, pboxes, gt_cls, gt_boxes)
print("cost matrix (rows=slots, cols=GT):\n", C.round(2))
g, o = greedy_match(C), optimal_match(C)
print("greedy  :", g, "-> unique?", len(set(g.values())) == len(g))
print("hungarian:", o, "-> unique?", len(set(o.values())) == len(o))

# Hungarian loss (Eq. 2): matched slots get class NLL + box loss, others -> "no object" (weight 0.1)
loss = 0.0
matched = set(o.values())
for j, i in o.items():
    loss += -np.log(probs[i, gt_cls[j]]) \
            + 5.0 * np.abs(pboxes[i] - gt_boxes[j]).sum() + 2.0 * (1 - giou(pboxes[i], gt_boxes[j]))
for i in range(N):
    if i not in matched:
        loss += 0.1 * -np.log(probs[i, num_classes])   # eos_coef = 0.1
print("Hungarian loss:", round(float(loss), 3))
print("unmatched (pushed to 'no object'):", sorted(set(range(N)) - matched))

# --- case where greedy breaks uniqueness: both GTs prefer slot 0 ---
C2 = np.array([[-3.0, -2.5],
               [-1.0, -2.0],
               [ 4.0,  4.0]])
g2, o2 = greedy_match(C2), optimal_match(C2)
tot = lambda m: sum(C2[p, j] for j, p in m.items())
print("greedy   :", g2, "unique?", len(set(g2.values())) == len(g2))
print("hungarian:", o2, "total cost", tot(o2))
```

실행 결과(요약): 첫 블록에서 매칭은 `{0: 0, 1: 2}`, 슬롯 1이 슬롯 0과 같은 물체를 잡았지만 매칭되지 못해 **∅로 밀려난다**(`unmatched [1, 3, 4]`). 마지막 블록에서 greedy는 `{0: 0, 1: 0}`으로 두 GT가 같은 슬롯을 가져 일대일이 깨지고, Hungarian은 `{0: 0, 1: 1}`(총 비용 -5.0)로 유일성을 지킨다. 이 제약이 NMS 없는 학습의 핵심이다.

## 트레이드오프와 함정

실험 결과 (COCO val, Table 1; GFLOPS/FPS, 파라미터, AP / APS / APM / APL):

| 모델 | GFLOPS/FPS | 파라미터 | AP | APS | APM | APL |
|---|---|---|---|---|---|---|
| Faster RCNN-FPN+ | 180/26 | 42M | 42.0 | 26.6 | 45.4 | 53.4 |
| Faster RCNN-R101-FPN+ | 246/20 | 60M | 44.0 | 27.2 | 48.1 | 56.0 |
| DETR (R50) | 86/28 | 41M | 42.0 | 20.5 | 45.8 | 61.1 |
| DETR-DC5 | 187/12 | 41M | 43.3 | 22.5 | 47.3 | 61.1 |
| DETR-R101 | 152/20 | 60M | 43.5 | 21.9 | 48.0 | 61.8 |
| DETR-DC5-R101 | 253/10 | 60M | 44.9 | 23.7 | 49.5 | 62.3 |

(`+`는 논문이 GIoU, random crop, 9x schedule로 강화한 Faster R-CNN baseline.)

- **큰 물체는 강하고 작은 물체는 약하다.** DETR은 APL에서 +7.8, APS에서 -5.5(Faster R-CNN-FPN 대비, Sec. 4.1). 전역 self-attention이 큰 물체 추론에 유리한 반면, 단일 스케일 32배 다운샘플 특징맵이라 작은 물체 해상도가 부족하다. DC5로 해상도를 올리면 encoder attention 비용이 16배 늘어 전체 계산량은 2배가 된다(Sec. 4).
- **학습이 오래 걸린다.** ablation 기본 설정이 300 epoch(16 V100, 약 3일), Faster R-CNN과 비교하는 긴 schedule은 500 epoch다. Faster R-CNN baseline은 약 109 epoch(9x)다. 이 느린 수렴이 후속 연구의 주된 타깃이 되었다.
- **학습 안정화 설정**: backbone lr 1e-5, transformer lr 1e-4, AdamW, gradient clipping 0.1. backbone lr을 한 자릿수 작게 두는 것이 초기 학습 안정에 중요하다고 한다(부록 A.4).
- **Ablation 요약**: encoder 층을 0으로 하면 AP 36.7(6층 40.6, 12층 41.6, Table 2). 위치 인코딩을 아예 빼면 32.8(-7.8, Table 3). loss에서 GIoU를 빼면 -0.7, $\ell_1$만 쓰면 35.8(-4.8, Table 4). FFN을 빼면 -2.3 AP. Decoder 첫 층 출력에는 NMS가 도움이 되지만(자기 자신 외의 관계를 못 보므로 중복 예측) 마지막 층에서는 오히려 TP를 지워 AP가 약간 떨어진다(Fig. 4).
- **함정**: N은 고정 상한이므로 객체가 N개를 넘는 장면에는 구조적으로 약하다. Hungarian 매칭은 매 iteration 학습에서 불안정해지기 쉽다는 점(매칭이 바뀌면 같은 슬롯의 목표가 바뀜)은 이 논문이 직접 분석하지는 않았고, 후속 연구들이 지적한 부분이다.
